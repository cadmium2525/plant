# BOTANICAL ODDITIES｜奇妙な植物の小さな温室

スマホで遊ぶブラウザゲーム。種ガチャで手に入れた塊根植物・多肉植物を鉢に植えると、30〜60秒ほどで3Dの植物へ成長します。
同じ種類でも、幹の膨らみ・曲がり・分岐・葉の付き方は1粒ごとに異なります。育った個体は図鑑に登録し、鉢を飾り付けてカード画像としてSNSに共有できます。

- 技術: TypeScript + Vite + Three.js（WebGL）
- 公開: GitHub Pages（静的配信のみ、サーバー・外部API・課金なし）
- セーブ: 端末内の IndexedDB（設定のみ localStorage）。設定画面から JSON バックアップの書き出し・読み込みが可能

## 遊び方

1. **種ガチャ** — 育成ポイントで種をひく（初期 120pt、1回 40pt）。レア度と樹形のシルエットが先に分かります
2. **植え付け** — 鉢（丸鉢・筒鉢・浅鉢）と色を選んで植える
3. **観察** — 時間を圧縮した成長アニメーション。ドラッグで回転、ピンチで拡大。×2・×4・スキップあり
4. **図鑑登録** — 名前を付けて登録するとポイント獲得。初めて見つけた特徴にはボーナス
5. **スタジオ** — 鉢の色・模様・ラッピング・ラクガキ・ステッカー、背景（プリセット／好きな画像）、ライト、カードデザインを編集
6. **書き出し** — カード画像（4:5 / 9:16 の PNG）を Web Share API で共有、非対応端末ではダウンロード

ポイントが尽きて種もない場合は、無料の「おためし種」がもらえます。

## 収録植物（MVP）

| 植物 | 造形の特徴 | 主な個体差・希少変異 |
| --- | --- | --- |
| アデニウム | ぷっくりした塊根、太く短い枝、枝先のロゼット葉と花 | 頭数（多頭）、塊根の肥大（超肥大）、花色（白・黄・絞り）、扇状化風、斑入り、矮性 など |
| デカリア | ジグザグに折れ曲がる枝、節ごとの小葉とトゲ | 株立ち、超ジグザグ、塊根化、扇状化風、斑入り、ねじれ など |

レア度（コモン／レア／スーパーレア／幻の個体）は植物の種類ではなく、**生成された形の特徴**から判定します。「ミニマル」「ひょろ長」のような可愛い失敗形も特徴として記録されます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー（--host 付きなので同じLANのスマホから確認できます）
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # ビルド結果の確認
```

シード再現の確認用に、`?debug=adenium:12345` のように URL を付けると指定シードの個体を直接表示できます。

## GitHub Pages で公開する

1. リポジトリを Public にする（無料プランの場合）
2. GitHub の **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
3. `main` ブランチに push すると `.github/workflows/deploy.yml` がビルドして公開します
   （`https://<ユーザー名>.github.io/<リポジトリ名>/`。`vite.config.ts` の `base: './'` によりサブパスでも動作します）

## 構成

```
src/
  rng.ts              シード付き乱数（mulberry32）
  plant/
    generate.ts       遺伝パラメータ → 骨格（節・枝・葉・花・トゲ・塊根）の生成
    mesh.ts           骨格から Three.js メッシュを作り、時刻 t の姿に更新（成長アニメーション）
    rarity.ts         形状の特徴から希少度を判定、特徴カタログ
    species.ts        植物種の定義
    silhouette.ts     ガチャで見せるシルエット
    names.ts          個体の仮名
  pot.ts              鉢（形状・展開図テクスチャ・ラクガキ・ステッカー）
  stage.ts            3D ステージ（WebGLRenderer は1つを全画面で共有）
  card.ts             カード画像の合成・共有/保存
  store.ts            IndexedDB セーブ、設定、JSON バックアップ
  game.ts             ガチャ抽選・報酬
  ui/                 各画面（ホーム・ガチャ・育成・個体詳細・スタジオ・図鑑・設定）
```

個体は `speciesId + seed` だけで保存し、表示時に同じ骨格を再生成します（同一シード → 同一樹形）。

## 性能面の工夫

- 描画解像度を devicePixelRatio の上限（軽量1.0 / 標準1.5 / 高画質2.0）で制限
- 枝は1つのジオメトリに統合し、頂点位置だけを毎フレーム更新。葉・花・トゲ・化粧砂利は InstancedMesh
- 影はシャドウマップを使わず、放射グラデーションの接地影で代用
- 静止中は描画をスキップ（カメラ操作・成長中のみレンダリング）
- 温室・図鑑の一覧は静止サムネイル画像
- WebGL 非対応・ストレージ不可の環境では説明画面を表示

## 注意

3D描画に three.js（MIT License）を使用しています。その他の素材（植物・鉢・背景・アイコン）はすべてプログラムで生成しています。
